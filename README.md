# 物理自习室

作者：Ktyu白驹过隙

在线使用：https://ktyu-t.github.io/physics-lab/

9 个阶段、36 节循序课堂；8 个知识主题、120 道原创英文选择题与中文解析、3 组可操作实验、公式卡和错题本。支持 10 / 20 / 40 题混合练习，每个主题 15 题，以及只练未做题。

最终模拟考限时 3 小时：40 道选择题（40 分）＋理论综合题 80 分＋实验题 40 分。题型参考 IGCSE，全部为原创；包含解释、数据分析、实验设计、计算与作图。选择题自动计分，主观题交卷后按评分点自评；支持保存草图与刷新继续。

实验包括导轨小车、波槽、电路，支持测量记录和图像。历年真题与评分标准入口：[PapaCambridge Physics 0625](https://pastpapers.papacambridge.com/papers/caie/igcse-physics-0625)。站内题目为原创，外部真题版权归原权利人。

网站无需登录，学习进度仅保存在访问者自己的浏览器。下载 Code → Download ZIP，解压后用电脑浏览器打开 index.html 即可离线使用，参考资料链接需要联网。

内容依据与科学来源见网页“资料与来源”。
